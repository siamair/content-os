# เลือก Provider และ Model

ค่าทั้งหมดอยู่ใน `models.json` แก้ที่นั่นที่เดียวเมื่อ slug หรือ endpoint เปลี่ยน

| Alias (`--model`) | Provider หลัก | เหมาะกับ | หมายเหตุ |
|---|---|---|---|
| `gpt-image-2` | kie | ค่าเริ่มต้น ภาพสมจริง ตัวอักษรในภาพแม่น ทำตามคำสั่งละเอียด | ราคาสูงกว่า |
| `nano-banana-pro` | kie หรือ gemini | คุณภาพสูง แก้ภาพจากภาพอ้างอิงเก่ง รักษาตัวตน (identity) ดี | Gemini 3 Pro Image |
| `nano-banana-2-lite` | gemini หรือ kie | ร่าง (draft) เร็วและถูก | ใช้วนหาไอเดียก่อนจบงาน |

## เส้นทาง (fallback)

- `--provider kie` (ค่าเริ่มต้น): ลอง Kie ก่อน ถ้าไม่มี key / เครือข่ายถูกบล็อก / งานล้มเหลว → สลับไป Gemini อัตโนมัติ
- `--provider gemini`: ลอง Gemini ก่อน ล้มเหลว → สลับไป Kie
- เมื่อสลับ สคริปต์จะใส่ `"fallback_from"` และเหตุผลใน JSON output ต้องบอกผู้ใช้เสมอ
- โมเดลที่ไม่มีบน provider ปลายทาง จะถูกแมปไปโมเดลที่ใกล้ที่สุดตาม `fallback_model` ใน `models.json`

## ความละเอียด

`--resolution 1K|2K|4K` (ค่าเริ่มต้น 2K) ร่างที่ 1K แล้วค่อยรันตัวที่ชอบที่ 2K/4K

## Aspect ratio ที่รองรับทั่วไป

1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9
