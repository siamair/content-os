# แหล่งแสง (Lighting)

| แสง | ลักษณะ | อารมณ์ |
|---|---|---|
| soft window light | นุ่ม ไล่เงาเนียน มาจากด้านข้าง | สงบ อบอุ่น สมจริง |
| golden hour | อุ่น ต่ำ เงายาว | โรแมนติก nostalgic |
| blue hour | ฟ้าน้ำเงินเข้ม แสงไฟเมืองอุ่น | เงียบ ลึกลับ |
| overcast daylight | แบน นุ่ม ไม่มีเงาแข็ง | เป็นกลาง สารคดี |
| harsh midday sun | เงาแข็ง คอนทราสต์สูง | ร้อน ดิบ |
| softbox / large diffuser | สตูดิโอ นุ่ม ควบคุมได้ | สินค้า portrait |
| hard flash | เงาคม ขอบชัด | แฟชั่น ป๊อป |
| rim / back light | ขอบสว่างแยกตัวแบบออกจากฉากหลัง | ดราม่า ขนฟูเป็นประกาย |
| Rembrandt lighting | สามเหลี่ยมแสงที่แก้ม | portrait คลาสสิก |
| practical lights | โคมไฟ/จอในฉากเป็นแหล่งแสง | cinematic |
| neon | สีจัด สะท้อนพื้นเปียก | cyberpunk ยามค่ำ |
| candlelight | อุ่นมาก วูบไหว | ใกล้ชิด |
| volumetric haze / god rays | ลำแสงเห็นในอากาศ | ยิ่งใหญ่ ศักดิ์สิทธิ์ |

ระบุให้ครบ 3 อย่าง: **แหล่ง + ทิศทาง + คุณภาพ/สี** เช่น "soft window light from camera left, warm 4000K, gentle fill from a white wall"
