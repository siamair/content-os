# Style: Technical Annotation

ภาพอธิบายพร้อมคำบรรยายชี้ส่วนประกอบ

| องค์ประกอบ | ค่าแนะนำ |
|---|---|
| Vantage | clear orthographic or 3/4 view, object centered with space for callouts |
| Lighting | neutral even lighting |
| Mood | precise, educational |
| Style | technical illustration with leader lines and labeled callouts, blueprint or clean infographic style |

Subject และ Setting มาจากคำขอของผู้ใช้เสมอ ฉากนี้กำหนดแค่ 4 องค์ประกอบด้านบน

**หมายเหตุ:** ระบุป้ายกำกับทุกอันเป็นรายการในเครื่องหมายคำพูด
