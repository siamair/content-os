# Style: Anime

| องค์ประกอบ | ค่าแนะนำ |
|---|---|
| Vantage | dynamic angle, character-focused composition |
| Lighting | cel shading, bright rim light, painted sky |
| Mood | energetic, emotional, whimsical |
| Style | anime key visual, clean line art, cel-shaded, vibrant palette, detailed background painting |
