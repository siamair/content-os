# มุมกล้องและเลนส์ (Vantage)

| คำ | ผลลัพธ์ | ใช้เมื่อ |
|---|---|---|
| eye-level | เป็นธรรมชาติ เท่าเทียม | portrait, สัตว์เลี้ยง |
| low angle | ตัวแบบดูยิ่งใหญ่ มีอำนาจ | ฮีโร่, สินค้าหรู |
| high angle | ตัวแบบดูเล็ก น่ารัก เปราะบาง | ลูกสัตว์, เด็ก |
| top-down / flat lay | จัดวางเป็นระเบียบ | อาหาร, สินค้าหลายชิ้น |
| over-the-shoulder | ดึงผู้ชมเข้าฉาก | เล่าเรื่อง |
| Dutch tilt | ไม่มั่นคง ตึงเครียด | ฉากระทึก |
| close-up | เน้นอารมณ์/ดวงตา | portrait |
| medium shot | เห็นท่าทางและบริบท | lifestyle |
| wide establishing | เห็นสถานที่ | cinematic |
| 24-35mm | กว้าง มีบริบท บิดขอบเล็กน้อย | street, interior |
| 50mm | ใกล้เคียงสายตา | ทั่วไป |
| 85mm | หน้าสวย ฉากหลังละลาย | portrait |
| 100mm macro | รายละเอียดใกล้มาก | texture |
| 200mm | บีบระยะ ฉากหลังแน่น | กีฬา, สัตว์ป่า |
| f/1.4–2.0 | ชัดตื้น โบเก้ | แยกตัวแบบ |
| f/8–11 | ชัดทั้งภาพ | landscape, product |
| motion blur / panning | การเคลื่อนไหว | วิ่ง, รถ |
