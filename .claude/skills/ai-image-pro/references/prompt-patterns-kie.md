# Prompt Patterns: Kie AI (GPT Image 2 และโมเดลใน Kie Market)

- GPT Image ทำตามคำสั่ง **ละเอียดและยาว** ได้ดี ใช้โครง AVB-6 เต็มรูปแบบได้เลย
- ตัวอักษรในภาพ: ใส่ข้อความเป๊ะในเครื่องหมายคำพูด + ระบุตำแหน่ง ฟอนต์ ขนาด
- ภาพอ้างอิง: สคริปต์อัปโหลดไฟล์ local เป็น URL ให้อัตโนมัติ (Kie ต้องการ URL ไม่ใช่ไฟล์) แล้วใน prompt ให้บอกบทบาทภาพ "Use the reference image as ..."
- งานเป็น async: สร้าง task → poll สถานะ → ดาวน์โหลด URL ผลลัพธ์ทันที (URL หมดอายุภายในไม่กี่ชั่วโมง)
- ถ้าได้ 404/422 แปลว่า slug หรือชื่อฟิลด์ใน `input` เปลี่ยน ให้แก้ใน `models.json` ส่วน `kie`
